    GETTING STARTED
    Run a SAP-to-robot process step by step
    
      
      
        
    1. 1. Load Asset Management.Load Example selects autonomous inspection and opens the 3D twin. Model layout remains editable.
      2. 
        
    2. 2. Inspect context.Open SAP BDC Connect for mock shared products and contracts. Connection settings are limited to SAP BDC Connect and Joule.
      3. 
        
    3. 3. Explore local domains.Asset Management, Manufacturing, Orchestration and Logistics select their matching scenario. These workspaces are not native SAP applications.
      4. 
        
    4. 4. Plan locally.Joule is NOT CONNECTED. Enter a goal and start a bounded local mock plan; inspect the actual returned plan and trace.
      5. 
        
    5. 5. Inspect and run.Open a physical object for GRAFCET, routine code and I/O bindings. Preview steps, run the twin, or compare DES experiments.
      6. 
        
    6. 6. Exercise approval.Assisted mode pauses for your approval or rejection before each simulated action. Shadow uses synthetic inputs; live execution is locked.
      7. 
        
    7. 7. Review evidence.Open Evidence to view the event timeline, export recorded routine events and approvals, or load the actual audit trail. Save Snapshot saves model edits separately.
